# Earnings Tracker App

A lightweight web app for small business owners to track daily earnings and visualize their revenue over time.

## What it does

- Log daily earnings quickly
- View earnings history at a glance
- Identify best performing days
- Simple, clean interface — no accounting knowledge required
- Works directly in the browser, no installation needed

## Built with

- HTML5
- CSS3
- JavaScript

## Who is this for

Small business owners in Miami — food trucks, salons, freelancers — who want a simple tool to track how much they make each day without complex software.
